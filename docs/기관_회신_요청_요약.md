## 2. 관리자 권한 코드: 새로 만들지, 기존 코드로 묶을지

스키마에 권한 코드가 없는 업무는 새 코드를 만들지 않고 아래 기존 코드로 묶어 두었다. 구조 권한(`AU.GRANT_W`)은 시스템 배정(`SK.SYSTEM`)이 묶음 전체로 가질 수 있지만, 회원 정보·집계 자료·개인정보 파기처럼 업무 자료를 바꾸는 일은 묶음 배정만 인정한다(R20, ADR-089·090).

|---|---|---|---|---|
| 교육기수 관리 | `AU.CONF_W` | 코드는 스키마 설계안 v0.5에 이미 있다. 기수 관리에 쓰는 것을 확인 | R1 | 가정대로 진행(11-17) |

## 3. 콘텐츠·약관 유형 코드(CT)를 한 번에 추가할지

## 회신이 없을 때 생기는 일

- 1장 항목은 해당 기능이 없거나 일부만 되는 채로 출시된다. 보존기간이 정해지지 않은 자료는 계속 쌓이므로 운영 시작 전에 회신이 필요하다.
- 권한 코드 항목은 기존 코드 묶음으로 운영되며, 나중에 신설하면 배정 데이터를 옮겨야 한다.
- 컬럼 추가 항목은 위 가정대로 동작하고 해당 기능은 제한된 채 출시된다. 컬럼이 생기면 임시 저장한 값을 옮겨야 하는 항목(R26, R34~R36)이 있다.
- 정책·값 항목은 표시 문구가 `TBD`·`검토 중`으로 남아 운영 시작 전에 채워야 한다.
