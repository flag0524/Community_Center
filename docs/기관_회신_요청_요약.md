## 회신 현황

2026-11-17 16:20에 자치행정과 담당자 1명이 회신 페이지에서 45개 항목 전부 「가정대로 진행」으로 회신했다. 아래 표의 회신 칸에 반영했다.

「가정대로 진행」은 항목에 따라 뜻이 다르다.

- **확정**: 임시 권한·임시 저장·화면 방식·기준 값을 그대로 쓰라는 답이다. 45개 중 33개 항목이 여기에 해당한다. 구현은 이미 그렇게 되어 있어 바뀌는 것이 없다.
- **열리지 않음**: 가정이 「기능 없음」이거나 「값 미정」인 항목은 이 답만으로 기능이 열리지 않는다. 45개 중 12개 항목(같은 주제로 묶어 아래 9행)은 구체적인 답이 따로 필요하다.

## 회신이 없을 때 생기는 일

- 1장 항목은 해당 기능이 없거나 일부만 되는 채로 출시된다. 보존기간이 정해지지 않은 자료는 계속 쌓이므로 운영 시작 전에 회신이 필요하다.
- 권한 코드 항목은 기존 코드 묶음으로 운영되며, 나중에 신설하면 배정 데이터를 옮겨야 한다.
- 컬럼 추가 항목은 위 가정대로 동작하고 해당 기능은 제한된 채 출시된다. 컬럼이 생기면 임시 저장한 값을 옮겨야 하는 항목(R26, R34~R36)이 있다.
- 정책·값 항목은 표시 문구가 `TBD`·`검토 중`으로 남아 운영 시작 전에 채워야 한다.
