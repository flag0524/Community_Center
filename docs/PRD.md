## 1. 배경과 목표

### 1.1 현행 문제
- 수강신청을 방문 접수와 계좌이체로 받고 있어 접수 기간에 주민이 센터를 직접 찾아야 한다.
- 정원·대기 관리가 수작업이라 선착순 공정성과 환불 처리 이력을 증빙하기 어렵다.
- 고령 주민이 많은데 기존 웹사이트는 정보 탐색 위주라 신청까지 이어지는 흐름이 없다.

### 1.2 제품 목표
| # | 목표 | 측정 기준 |
|---|---|---|
| G1 | 수강신청을 **온라인 100%** 로 전환한다 | 시범 기수 신청 중 온라인 비율 100% (RQ-FUN-FN-016, FN-034) |
| G2 | 선착순·대기·결제기한을 **서버 기준으로 공정하게** 처리한다 | 정원 100 / 신청 500 검수에서 정원 초과·이중 배정 0건 (FN-034) |
| G3 | 결제·환불 금액을 **원장 단위로 추적**한다 | 부분환불 동시 요청 시 원결제액 초과 0건 (FN-045) |
| G4 | 고령 주민도 혼자 신청할 수 있게 한다 | 쉬운 화면으로 탐색→신청 안내까지 단계 표시 (FN-009, FN-010) |
| G5 | 동시 사용자 500명에서 주요 API p95 3초 이내 | 성능시험 (RQ-PER-NF-001) |

## 2. 사용자

| 사용자 | 설명 | 주요 과업 |
|---|---|---|
| **주민(비회원)** | 강좌 정보를 찾는 사람 | 강좌 탐색, 안내 확인, 공지·자료 조회 |
| **주민(회원)** | SMS 본인확인을 마친 회원 | 수강신청, 결제, 취소·환불, 후기·문의 작성 |
| **고령 주민** | 쉬운 화면 사용자 | 큰 글자로 강좌 찾기 → 신청 방법 → 내 신청 확인 |
| **강사(회원)** | 승인된 강사 | 강사 지원, 담당 강좌 출석 입력 |
| **센터 운영담당자** | 운영묶음(센터) 범위 관리자 | 강좌·기수·일정·시설 관리, 신청·결제 대조, 환불 승인·집행, 감면 심사, 게시판·문자 |
| **시스템 관리자** | 구조·권한 관리자 | 권한 배정, 공통 코드, 운영 설정 (업무정보 전체조회 권한은 없음, FN-056) |

> 운영묶음은 센터 단위 데이터 경계다. 시범은 조리읍 1개소다. 17개 동·5개 묶음은 설계 배경일 뿐 확정 명단이 아니다(RQ-DAR-NF-001).

## 3. 핵심 사용자 흐름

### 3.1 유료 강좌 수강신청 (가장 중요한 흐름)
```
강좌 목록/검색 ─▶ 강좌 상세 ─▶ [로그인] ─▶ 수강신청(필수 확인)
                                              │
               ┌──────────────────────────────┼─────────────────────────────┐
               ▼                              ▼                             ▼
     자리 배정 (결제대기)            정원 초과 → 대기 접수          결제예정 0원 → 즉시 수강확정
     배정시각 + 600초 기한           (정원 미점유, 순번 부여)        (PG 거래 생성 안 함)
               │                              │
               ▼                              │ 빈자리 발생 시 자동 승격 + SMS
     수강료 결제(PG: 카드/실시간계좌이체) ◀───┘ (새 배정시각 + 600초)
               │
     ┌─────────┼──────────────┬─────────────────┐
     ▼         ▼              ▼                 ▼
  결제 완료  결제 실패     결과 확인 중       기한 만료
  (수강확정) (기한 내 재시도) (재결제·재배정 차단) (정원 반환 → 다음 대기자)
```

### 3.2 취소·환불
- 결제 전 취소는 신청취소로 끝나고 정원을 반환한다(FN-037).
- 결제 후에는 환불 신청 → 담당자 검토(승인/반려) → 집행 → 집행 결과 확인 후 **환불완료** 표시 순서다(FN-043, FN-044).
- 반환액은 개강 전 전액, 개강 후 당월분 제외 금액이다. 기관 승인본이 다르면 승인본이 우선한다(FN-017, FN-043).

### 3.3 감면 (50%)
- 대상은 조리읍 거주 기초생활수급자·국가유공자·등록 장애인 본인이며 기수당 1강좌다(FN-038).
- **접수 시작 전**에 증빙을 제출하고 담당자 승인을 받아야 신청 시 감면이 적용된다. 10분 기한은 감면 때문에 연장되지 않는다.
