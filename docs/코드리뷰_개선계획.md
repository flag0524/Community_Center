### 확인이 더 필요한 점
- 관리자 로그인 잠금 시간. 사용자가 고른 선택지에 "15분으로 늘린다"가 들어 있었으나 현재 5회·5분은 기관 확정값이다(ADR-085·086). 해당 단계에서 기관 확정값을 바꾸는 것이 맞는지 다시 묻고 진행한다.
- PG·SMS 실어댑터 재리뷰(보안 중-4)는 업체가 정해진 뒤에만 가능하다. 지금은 규약 시험을 더 강하게 하는 준비만 한다.

## 지키는 규칙
- 동결된 규칙은 깨지 않는다. 스키마 변경은 설계안 개정과 새 Alembic 버전으로만 하고, 0001 SQL은 건드리지 않는다.
- 원장 INSERT-only, 잠금 순서(강좌 → 회원·신청 → 결제 → 환불), 트랜잭션 안 외부 호출 금지는 그대로 둔다.
- 새 기능이나 코드값이 필요하면 만들지 않고 요청서로 남긴다.
- 각 단계 끝에 전체 시험을 돌리고 skipped 수를 확인한다.
